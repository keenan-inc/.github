## How I work

- **Security is a build requirement, not a review step.** Threat model first, dependency hygiene enforced in CI, secrets never in the repo.
- **Local-first by default.** Your data stays on your machine unless there is a reason it shouldn't.
- **Finished over feature-rich.** A small tool that is done beats a large one that is perpetually 0.9.
